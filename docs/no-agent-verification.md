## 未验证及上线限制

- 手机浏览器实测受执行环境 socket/浏览器启动限制，未完成、无截图；不是移动端验收通过。
- 未运行全后端数据库矩阵、MySQL/SQLite、真实支付回调/打款、生产 Redis 专项、容器镜像
  发布/部署或真实流量切换。全后端测试包只保证编译，实际执行范围如上。
- 有代理资金历史的既有站不承诺直接切换。来源批次/分片/经济分摊、信用 draw、非充值
  回执、未逆转现金奖励等可能保守阻断；需要单独审核的退休迁移，不能删记录/清零绕过。
- 必须先停全部旧写入者；不支持新旧混写。回退前必须核对新普通返利队列和消费恢复，
  不能覆盖切换后新增付款/消费事实。详见 `no-agent-edition.md`。
