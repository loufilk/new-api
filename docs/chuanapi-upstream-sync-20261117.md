## 合并边界

- 保留两个父提交。合并包含官方主干上此前缺少的 27 个提交，与官方单独部署是两回事。
- 保留万川钱包、资金终结幂等、用户拦截、候选分组、Responses 状态、后台任务生命周期、老风控配置和启动遮罩修复。旧敏感词的分组豁免仍生效，因此不在启动时自动运行上游的旧配置删除／全局过滤迁移。
- 吸收官方 Gemini 4 思考档位与文本合并、跨节点配置同步、插件支持与客户端错误不自动停用渠道等更新。New API 内的 Gemini 映射与独立 Gemini Web 适配器的账号目录是不同层；该合并不会部署适配器或变更现网渠道。
- 易支付空签名模式保留旧 MD5 兼容，RSA 需显式配置；不认识的模式拒绝，不回退到 MD5。现有回调结算和原始订单幂等规则不因升级切换。
- 生产已有的 `HTTP_BIND_ADDRESS` 优先；未设时支持官方的 `HOST`。pprof 仍只监听本地。

## 验收边界

在隔离工作树使用仓库声明的 Go 1.27.3 和 Bun 1.4.4。在运行 PostgreSQL／Redis 集成用例前先隔离测试数据，禁止复用线上连接。发布前应快照备份、在预生产做一次旧库升级演练并验证钱包支付回调、分组、工具流及取消。需要回退时先核对新旧镜像和 schema 的兼容性，不做手工破坏性降级。
